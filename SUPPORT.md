# Support

This repository is an engineering record, not a supported HomeLab distribution.

For a correction to something published here, open an issue with the affected page and the evidence behind the correction. For a new write-up, explain the engineering question and why the result would be useful beyond one local setup.

Questions about upstream products are usually better directed to the upstream project unless the question is specifically about a decision documented here.

Do not include private infrastructure details in public issues.
