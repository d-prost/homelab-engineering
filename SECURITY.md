# Security Policy

This repository contains public engineering notes, not the live HomeLab configuration.

## Reporting

For a security problem in this repository, use GitHub Private Vulnerability Reporting when available.

Do not place credentials, private infrastructure details or exploit information for a live environment in a public issue.

## Boundary

The private operational environment is outside the scope of this repository. Public examples should remain synthetic or generalized.

If sensitive material is committed here, treat the material as exposed first. Rotate or revoke affected credentials before cleaning repository history.
