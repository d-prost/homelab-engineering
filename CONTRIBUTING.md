# Contributing

This is a personal engineering repository, but corrections and focused improvements are welcome.

A useful change should improve one decision, experiment, incident note, recovery method or lesson without turning the repository into a general HomeLab wiki.

## Public boundary

Do not include:

- private hostnames or addresses;
- credentials, keys or tokens;
- exact backup or recovery locations;
- live inventory;
- personal data;
- private operational evidence.

The repository validation checks some of these mechanically, but review remains the final boundary.

## Pull requests

Keep pull requests narrow. Explain:

1. what is being clarified or corrected;
2. why the change is useful outside one private environment;
3. what information was intentionally left out.

Upstream product documentation should be linked rather than copied.
