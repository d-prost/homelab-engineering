# Experiments

Experiments answer one bounded question before they become architecture.

A useful experiment records:

- the question;
- the safe test boundary;
- what was changed;
- what was observed;
- what was not proven;
- whether the result was adopted, rejected or left open.

Disposable or non-critical targets are preferred when the test changes runtime behavior.

The goal is not to publish every trial. It is to preserve the experiments that changed a decision.
